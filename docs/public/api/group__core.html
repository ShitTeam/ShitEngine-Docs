引擎主循环、窗口、时间、日志与子系统上下文。

引擎生命周期由 Game 驱动：Init() 完成日志 → 配置 → 反射注册 → SDL → 窗口/渲染/输入/音频的初始化；Run() 执行「事件 → 更新 → 渲染」主循环； Destroy() 按初始化逆序清理。全部子系统实例由 EngineContext 按值持有， 支持多上下文（编辑器进程内预览即第二个上下文）。

关键类：

  • Game —— Init / Run / Destroy / SetPaused
  • EngineContext —— 子系统容器（多上下文）
  • Window / Time / Log / Config
  • System —— 场景系统基类（优先级排序驱动）
