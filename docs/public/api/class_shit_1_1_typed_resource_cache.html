详细描述

template<typename Res>
class Shit::TypedResourceCache< Res >

类型化缓存 —— 统一「查缓存 → 工厂创建 → 加载 → 插入」模式

加载失败不缓存：下次请求重试（文件后补/修复后自愈）。 经 TypedCacheBase 基类进入管理器注册表（无跨 DLL 模板实例化问题）。
