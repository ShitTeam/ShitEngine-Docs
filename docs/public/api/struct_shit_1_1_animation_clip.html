详细描述

动画剪辑（可序列化数据，P28）

一份动画剪辑描述"从某张精灵表纹理按网格切出的帧序列 + 播放参数"。 作为独立数据类，既可作为运行时/编辑器的动画数据，也可序列化为 .anim 资产 （AnimationClip 资产化）或内嵌进 Animator / AnimationComponent 的载体字符串。

frames 为 SpriteSheet 全局帧索引序列（与 AnimationComponent::play 的 frames 语义一致）。
