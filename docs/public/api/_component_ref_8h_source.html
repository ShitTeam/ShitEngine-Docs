3// P20: 组件引用（类似 Unity 的 Object 引用字段）
4//
5// ComponentRef<T> 是"可序列化的组件引用"：字段内只存目标组件的持久
6// UUID（64 位，随 .scene 落盘），get() 时经当前场景的 uuid → 组件索引
7// 懒解析。目标组件被移除/所属对象销毁后，get() 返回 nullptr——永不悬垂。
8//
9// 用法（配合反射扫描器，字段自动被识别为引用字段）：
10// SHIT_FIELD
11// Shit::ComponentRef<Shit::UIText> coinText; // 编辑器可拖拽赋引用
12//
13// if (auto t = coinText.get()) t->setText("...");
14//
15// 与 WeakComponentRef 的区别：WeakComponentRef 是"会话期弱引用"
16// （存 owner + 生命周期令牌，不序列化）；ComponentRef 是"持久引用"
17// （存 UUID，序列化到 .scene，目标销毁自动失效）。
18//
19// 约束：引用仅限同一场景（UUID 索引挂在 Scene 上）；跨场景引用解析为 null。
20// ═══════════════════════════════════════════════════════════════
