template<typename Key, typename Res, typename Hash = std::hash<Key>>
class Shit::ResourceCache< Key, Res, Hash >

泛型资源缓存外壳 —— 统一「查缓存 → 工厂创建 → 加载 → 插入」模式

加载失败不缓存：下次请求重试（与旧懒加载行为一致，文件后补/修复后自愈）。
