详细描述

类型擦除缓存接口 —— ResourceManager 按资源类型注册缓存，经此统一遍历/清理

引擎/插件侧新增的资源类型缓存都以此基类指针进入管理器的类型注册表， GetResourceByUuid / 全量清理 / 日志计数只依赖本接口（无跨 DLL 模板问题）。
