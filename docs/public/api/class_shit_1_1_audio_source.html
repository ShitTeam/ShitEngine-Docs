详细描述

音频播放组件 —— 挂在对象上播放场景音频

继承 Behavior（与 AnimationComponent 一致），由 BehaviorSystem 驱动： onStart 时按 PlayOnStart 自动播放；脚本中也可手动 play()/stop()/pause()。

音频路径与纹理同一约定（相对资源目录），播放句柄为共享引用—— 播完引擎自动回收；重新 play() 新建轨道替换旧句柄。
